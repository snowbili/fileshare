设置

怎么用

  1. 左面板是你共享出去的目录。把文件从资源管理器拖进左面板，文件就放进了共享目录。
  2. 另一台电脑打开本工具后，在右面板选中你，就能看到这些文件。
  3. 把右面板的文件拖到桌面或任意文件夹，浏览器会完成下载；也可以拖到左面板直接下载进本机目录。
  4. 把左面板的文件拖到右面板，就推送到对方（对方是本工具时落到它的接收目录）。
  5. 对方若是手机上的官方 LocalSend：右面板无法浏览（协议不支持），但可把文件拖到右侧推送过去，对方会弹出接受提示。
  6. 手机不装任何 App：点二维码，扫码即可在浏览器里下载你共享的文件。
首次运行若对方连不上：在这台电脑以管理员身份运行一次 firewall.cmd，放行 TCP 8099 与 UDP 53317。
